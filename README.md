# Netflix Clone

Projeto desenvolvido para reproduzir a experiência visual de uma plataforma de streaming, utilizando tecnologias de Frontend e Backend.

O projeto possui uma tela de seleção de perfis, catálogo de filmes, pesquisa, categorias e integração com uma API REST desenvolvida em Java com Spring Boot.

## Projeto online

Acesse:

https://netflixclone-3pva.onrender.com/

## Funcionalidades

- Seleção de perfil
- Catálogo de filmes
- Pesquisa por título, descrição e categoria
- Filmes populares
- Categoria de ação
- Categoria de ficção científica
- Informações dos filmes
- Posters dos filmes
- API REST para gerenciamento do catálogo
- Banco de dados
- Interface responsiva

#API
A aplicação possui uma API REST para trabalhar com os filmes.
GET    /api/filmes
GET    /api/filmes/{id}
POST   /api/filmes
PUT    /api/filmes/{id}
DELETE /api/filmes/{id}
